## 📖 О проекте
Учебный проект, представляющий собой сайт для туристов. В проекте реализована адаптивная вёрстка, работа с формами, интерактивными элементами и модальными окнами на чистом JavaScript.

## 🛠 Стек технологий
- **Разметка:** HTML5 (семантическая верстка, доступность)
- **Стилизация:** CSS3 (адаптивность, flexbox, grid)
- **Скрипты:** JavaScript (ES6+, работа с DOM, обработка событий)
- **Инструменты:** Git

## ⚙️ Как запустить проект локально
Так как проект использует чистый HTML, CSS и JavaScript, для его запуска не требуется установка зависимостей или сборщиков. Достаточно открыть файл `index.html` в любом браузере.
